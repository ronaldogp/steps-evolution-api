  • Acesse o site cloud.oracle.com. Mude pra o Brasil, se assim preferir.
  • Clique em Sign Up (Inscrever-se) e preencha o formulário.
  • Quando chegar na opção Customer type selecione Individual.
  • Anote o nome da conta.
  • O seu usuário é o e-mail utilizado para se cadastrar. Não é o nome da conta.
  • Depois que concluir todos os passos de cadastro, será necessário mudar do modo FREE para o modo PAGAMENTO CONFORME O USO (pay-as-you-go). Nenhuma cobrança será feita. Este processo de mudança pode demorar até uma semana. Quando for concluído você vai receber um e-mail.
  • Em algum momento será necessário instalar um app autenticador da Oracle para logar no site.
